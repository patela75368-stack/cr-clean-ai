# CR Clean AI

A free, self-hostable video optimization and metadata-cleaning starter.

## Features
- Video upload
- FFmpeg metadata cleanup and re-encoding
- Progress UI
- Processed video download
- Automatic temporary-file cleanup
- Mobile responsive UI
- No claim of removing copyright ownership or Content ID claims

## Run
1. Install Node.js 20+ and FFmpeg.
2. `npm install`
3. `npm start`
4. Open `http://localhost:3000`

For production, put the app behind HTTPS and use object storage for large files.
